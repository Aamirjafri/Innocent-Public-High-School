# The Innocent Public High School – Website

A modern, responsive school website created for **The Innocent Public High School**, Latifabad, Hyderabad, Pakistan.

## Features

- Clean & professional design (Navy + Gold theme)
- Fully responsive (mobile, tablet, desktop)
- Smooth scrolling navigation
- Sections included:
  - Home / Hero
  - About Us
  - Why Choose Us (Features)
  - Academics (Primary, Middle, High School)
  - Admissions process + CTA
  - News & Events
  - Contact form + details
  - Footer with quick links
- Mobile hamburger menu
- Contact form with basic validation (frontend only)

## How to Use

1. Open the folder `innocent-public-high-school`
2. Double-click `index.html` to open it in any browser
3. Or upload the entire folder to any web hosting (GitHub Pages, Netlify, cPanel, etc.)

## Files Structure

```
innocent-public-high-school/
├── index.html          ← Main website
├── css/
│   └── style.css       ← All styles
├── js/
│   └── main.js         ← Interactivity
├── images/             ← (empty – you can add photos later)
└── README.md
```

## Customization Tips

- **Change text**: Edit `index.html`
- **Change colors**: Edit CSS variables at the top of `css/style.css`
- **Add real photos**: Place images in the `images/` folder and update the HTML
- **Contact form**: Currently shows a success message only. To receive real messages, connect it to a service like Formspree, EmailJS, or your own backend.
